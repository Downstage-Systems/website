One box. Four jobs.

The timer is the headline act, but the same box earns its rack space all day.

Show timer server

Countdowns and cues on two HDMI outputs and every browser in the building, with spoken time calls and cue tones from the audio jack. The timer gets its own box, so your laptop's HDMI is free for slides and playback.

Stream Deck control room

Bitfocus Companion runs onboard, so a Stream Deck on the One drives your switcher, cameras, OBS and the timer. No Stream Deck? The Virtual Deck puts the buttons in any browser. Already run Companion at front of house? Satellite mode hands the One's decks to your own Companion.

Signage and dashboards

External Viewer puts any web page on either output: the day's schedule, slides, a dashboard. Two independent 1080p pages, managed from your phone.

Signal check

Test card, SMPTE bars, grid, grey ramp and an AV-sync pattern, drawn on the device at native resolution before any server is set up.

Three steps, then doors.

No app to install, no account to make, no cloud to depend on.

Power it on

Plug into the venue network, or don't. With no network, it opens its own WiFi and the front panel shows where to connect.

Point a browser

The front panel shows its address, like downstage-0000.local:8080. Build the rundown and set your views.

Doors

Confidence monitor at the podium, clock backstage, schedule in the lobby. Add five minutes and every screen updates at once.

Built for the bad day.

Everything here exists because something went wrong at a real gig once.

Watchdog failover

If the timer server drops, screens show a clean holding page and come back on their own.

Failsafe boot media

A second boot card rides inside, kept in sync. If the main drive fails, the One boots from the backup.

Updates that roll back

One button installs Downstage OS updates. A bad update rolls itself back.

No internet required

A battery-backed clock keeps real time through power cuts. Everything runs in the room.

Setup hotspot

No venue WiFi? It broadcasts its own network, with its password on the quick-start card.

Blackout button

Every output to black, one press, from any phone on the network. Back just as fast.

Show profile included

Ontime and Companion install with one click, already set up for doors.

One-button front panel

Tap for status, a big clock or the setup code. Hold three seconds for a clean shutdown.
